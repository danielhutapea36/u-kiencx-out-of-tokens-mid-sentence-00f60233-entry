The funniest possible one-line error message an AI agent shows when it runs out of tokens mid-sentence — the message itself gets cut off mid-word, performing the very failure it reports.

## The line

> Error: out of tokens. The rest of this message was going to be bril—

A flat "Error:" frame with the joke built into the cutoff: the severed "bril—" lets the reader finish the word in their own head. The punchline lands on the last character.

## Run it

```sh
python3 main.py
```

This writes the line to `/output/entry.txt` (68 characters, UTF-8, deterministic — repeated runs produce byte-identical output). The line is well within the 140-character limit, a single line with no trailing newline.
